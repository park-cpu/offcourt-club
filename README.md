# Offcourt Club

Offcourt 테니스클럽 운영 웹앱 — 일정 · 출석 · 대진 · 기록 · 순위 · 코인.
빌드 도구 없이 HTML/JS 파일만으로 동작해서 GitHub에서 파일을 고치고 올리면 바로 배포됩니다.

## 화면 구성 (하단 탭 5개)

| 탭 | 내용 |
|---|---|
| 홈 | 다음 일정 1개, 내 코인/전적/레이팅, 시즌 Top 3 |
| 일정 | 주간(월~일) 일정 → 일정 상세(경기장·코트·시간·예약자, 참가 신청, 게스트) |
| 경기 | 오늘 일정의 **출석**(도착 체크·귀가) / **대진**(자동·수동, 코트별 진행) / **결과** |
| 순위 | 시즌 순위(시즌 포인트) · 레이팅 순위 → 개인 프로필 |
| 내 정보 | 로그인, 내 정보·PIN 변경, 관리자 메뉴 |

## 규칙 요약

- **레이팅**: NTRP로 시작(3.0=1000, 0.5당 100점) → Elo 방식으로 경기마다 변동. 복식은 팀 평균.
  낮은 레이팅이 높은 레이팅을 이기면 크게 오르고, 점수차(6:0=×1.5 … 7:6=×1.0)도 반영.
- **시즌 포인트(순위 기준)** = 시즌 중 레이팅 변동 합 + 경기당 1점. 최소 5경기(설정 가능)부터 순위 등재.
- **경기 유형**: 코인전(승패·레이팅·코인) / 공식전(승패·레이팅) / 친선전(출석만).
- **코인**: 가입 3개, 도착 체크 시 +1, 코인전은 승리팀 각 +1 · 패배팀 각 −1, 베이글(상대 0게임)은 ±2.
  잔액은 마이너스가 될 수 있고, 게스트가 있거나 코인 1개 미만인 선수가 있으면 코인전 → 공식전 자동 전환.
- **대출**: 잔액 0 이하 + 남은 대출 없음 → 3코인 대출(설정 가능). 상환 전까지 출석 코인은 상환에 쓰임. 보유 코인 상환 · 관리자 탕감 가능.
- **게스트**: 대진에는 참여하지만, 게스트가 낀 경기는 승패·레이팅·순위에서 제외.
- **혼복**: 회원·게스트 성별 기준으로 각 팀 남1·여1 자동 대진.
- 코인·레이팅·순위는 **저장된 경기 기록에서 매번 다시 계산**하므로, 점수를 고치면 자동으로 바로잡힙니다.
- **권한**: 관리자 1명(회원 등록은 관리자만). 회원은 일정 등록, 참가/출석, 자기 경기 점수 입력(이미 입력된 기록도 참가자는 수정 가능).

세부 수치는 `js/rules.js`, 대진 알고리즘은 `js/matchmaker.js` 에서 조정합니다.

## 1. 체험 모드로 먼저 보기

`js/config.js` 의 `FIREBASE_CONFIG` 가 `null` 이면 데이터가 **그 브라우저에만** 저장되는 체험 모드입니다.
첫 화면의 “데모 데이터로 체험하기”를 누르면 가상 회원 14명으로 둘러볼 수 있어요 (모든 PIN `0000`).

로컬에서 열기:

```bash
python3 -m http.server 8765
```

→ http://localhost:8765

## 2. Firebase 연결 (회원끼리 데이터 공유 — 무료)

1. https://console.firebase.google.com → **프로젝트 추가** (애널리틱스 꺼도 됨)
2. 왼쪽 **빌드 → Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → **프로덕션 모드**
3. Firestore **규칙** 탭에 이 저장소의 `firestore.rules` 내용을 붙여넣고 **게시**
4. 프로젝트 설정(⚙️) → **내 앱 → 웹(</>)** 추가 → 표시되는 `firebaseConfig` 값을 복사
5. `js/config.js` 의 `FIREBASE_CONFIG = null;` 을 복사한 값으로 교체 후 커밋

처음 접속한 사람이 관리자로 등록됩니다. **배포 직후 관리자가 먼저 접속**하세요.

## 3. GitHub Pages 배포

1. GitHub에서 새 저장소 생성 (예: `offcourt-club`, Public)
2. 이 폴더를 푸시
   ```bash
   git remote add origin https://github.com/<계정>/offcourt-club.git
   git push -u origin main
   ```
3. 저장소 **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`** → Save
4. 1~2분 뒤 `https://<계정>.github.io/offcourt-club/` 에서 접속

휴대폰에서 “홈 화면에 추가”하면 앱처럼 쓸 수 있어요.

## 4. 버전 업데이트

1. 파일 수정
2. `js/version.js` 의 `APP_VERSION` 올리기 + `CHANGELOG.md` 에 한 줄 기록
3. 커밋 & 푸시 → GitHub Pages가 자동 반영 (휴대폰은 새로고침)

## 보안 참고

- 로그인은 “이름 + PIN 4자리” 방식입니다. 클럽 내부용으로 충분하지만, 은행 수준 보안은 아닙니다
  (Firestore 규칙이 공개 읽기/쓰기라 기술적으로 아는 사람은 DB를 직접 수정할 수 있음).
- 그래서 관리자 메뉴 → **백업 · 복원**에서 주기적으로 JSON 백업을 받아 두세요.
- 더 강한 보안이 필요해지면 Firebase Authentication(카카오/구글 로그인) + 규칙 강화로 올릴 수 있습니다.
